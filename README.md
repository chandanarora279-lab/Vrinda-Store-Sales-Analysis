# Vrinda Store – E-commerce Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing Vrinda Store's e-commerce sales data using Microsoft Excel. The objective is to understand sales performance, customer purchasing behavior, order trends, and sales distribution across different channels and regions.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Analysis and Visualization

## Dataset
The dataset contains approximately 31,047 order records with information about:
- Order ID and Customer ID
- Gender and Age Group
- Order Date and Month
- Order Status
- Sales Channel
- Product Category and Quantity
- Sales Amount
- Shipping City and State

## Key Analysis Performed
1. **Sales vs Orders:** Analyzed monthly sales and order trends.
2. **Gender Analysis:** Compared purchasing patterns between men and women.
3. **Order Status Analysis:** Evaluated delivered, cancelled, returned, and other order statuses.
4. **Age Group Analysis:** Studied purchasing behavior across different age groups.
5. **State-wise Analysis:** Examined sales distribution across Indian states.
6. **Channel Analysis:** Compared sales performance across different e-commerce platforms.
